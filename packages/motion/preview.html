What's new

Everything below is driven by data-vm-* attributes and scroll position. Nothing on this page interpolates a colour in JavaScript — the paint module writes a value at each keyframe and CSS transitions carry it.

scale-x and scale-y

scale was the only transform without axis variants, so scaling one axis was impossible. Two schema rows, 18 bytes.

radius, and one corner overriding it

Animating all four corners used to mean four identical attributes. radius is declared before the individual corners, so a specific corner wins — the way round CSS itself works.

radius
all four at once
override
top-left holds, the rest tighten
<div data-vm
     data-vm-radius="0% 65px, 100% 8px"
     data-vm-radius-top-left="0% 65px, 100% 65px"></div>

@verajs/motion/paint — 621 bytes, opt-in

A property module carrying its own validator and its own write path. The runtime never learns what a colour is. Values are not interpolated: each one gets a slot, the curve steps between slots, and the CSS transition inertia already builds does the animating.

gradient → colour → colour
box-shadow lifting

colour + border-colour

Two packed properties on one element, both stepping under a transition.

import { createMotion, wireMotion } from '@verajs/motion';
import { paint } from '@verajs/motion/paint';

wireMotion(paint);

wireMotion() — a property nobody shipped

Defined in this page's own script, not in the library. A module is a plain object; the apply path was already generic over cssFunction and cssProperty, so a wired property needs no changes anywhere.

hue
a filter function, wired at runtime

letter spacing

A plain cssProperty, wired the same way.

composes with bands and keyframes like any built-in
wireMotion([
  { attribute: 'hue', category: 'filter', cssFunction: 'hue-rotate',
    defaultUnit: 'deg', units: ['deg'], initial: 0 },
  { attribute: 'tracking', category: 'text', cssProperty: 'letter-spacing',
    defaultUnit: 'px', units: ['px','rem','em'], initial: 0 },
]);

The grammar holds a CSS value now

Keyframes split on commas at paren depth zero, and position splits from value at the first whitespace. Before that, any value containing a space or a comma was refused before a parser saw it — which is every gradient and every shadow.

three keyframes, each with spaces and commas inside
data-vm-shadow="0% 0 1px 2px rgb(0 0 0 / 0.08),
                         50% 0 12px 24px rgb(59 76 202 / 0.35),
                         100% 0 3px 6px rgb(0 0 0 / 0.15)"
