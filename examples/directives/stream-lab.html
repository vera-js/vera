The wiring — the whole script

The whole surface: data-vd-stream="{ url, event, into, send, status, animate }". The URL's scheme picks the transport — http(s) is server-sent events (the platform reconnects it by itself; kill the server and watch the badge, then bring it back), ws(s) is a WebSocket (the pack reconnects it, capped backoff). Every pushed JSON object is a state patch; anything else is markup, same-origin only. Two elements on one URL share one connection.
