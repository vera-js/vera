<vera-select>

@verajs/ui's first component, served as production bundles through an importmap — the CDN shape, no build. Open DevTools and poke; every internal node is a named part.

Default

Shadow DOM, built-in markup, zero configuration. Keyboard: focus, ↓, arrows, Enter, Escape.

Multi + search

multi keeps the menu open and toggles; typing filters; disabled rows are skipped.

Themed by token

Page CSS: .tokened { --vera-accent: teal; --vera-radius: 999px } — no selectors into the component.

Styled by ::part()

.parted::part(trigger) and ::part(option) — the page reaches through the shadow boundary.

Light DOM

Same component, light attribute: no shadow root, parts addressable as plain [part='trigger'] selectors.

Your markup, slotted

The trigger below is page markup with a page class — the component wires behavior and data-state onto it.

Form-associated

A real form control via ElementInternals: submits, resets, appears in FormData.
