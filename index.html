VeraJS

One example per consumption mode.

  • npm + TypeScript
    Bare specifiers resolved by a bundler, as an installed consumer would. Served by this vite dev server, with @verajs/* aliased to package sources.
  • Buildless (CDN / CodePen)
    Importmap plus native ES modules, no toolchain. Deliberately not served from here — vite would resolve the bare specifiers itself and bypass the importmap, so the example would silently exercise sources instead of the built bundles.
    Run it with its own plain static server:
    npm run build && npm run dev:cdn → localhost:5174/examples/cdn-js/
  • SSR
    Server-side rendering through @verajs/ssr — vera-native, Node-only, and with no dependencies at all.
    npm run dev:ssr → localhost:3000
